# Business AI Kit — стартовый набор для предпринимателя

Пять скиллов для Claude (или Codex), чтобы за один вечер собрать **свою рабочую AI-систему из обычных файлов**: цель, контекст бизнеса, источники данных, одна рутина, ежедневный чек-ин. Без кода, без сервера, без подписок сверх Claude.

Автор — Ильнар Керимов, [ilnar-ai.ru](https://ilnar-ai.ru), Telegram [@iilnar_ai](https://t.me/iilnar_ai). Набор используется на потоке «Бизнес на AI». Лицензия MIT — берите, адаптируйте, встраивайте.

---

## Как начать (2 минуты)

Дайте Claude ссылку на этот репозиторий и скопируйте промт:

```
Вот стартовый набор: https://github.com/iilnar-ai/business-ai-kit
Я предприниматель, своей AI-системы ещё нет. Не ставь всё подряд.
Сначала прочитай README и skills/business-starter/SKILL.md.
Помоги мне собрать минимальную папку под мой бизнес: цель, контекст, источники данных, одна рутина и простой ежедневный чек-ин.
Ничего не выдумывай про мой бизнес — спрашивай. Не копируй чужие скиллы без адаптации под меня.
```

Через час у вас папка из 5 файлов, которую Claude читает в начале каждого чата:

```
мой-бизнес/
├── CLAUDE.md          ← как со мной работать (Codex читает AGENTS.md)
├── goal.md            ← одна цель на месяц
├── about-business.md  ← кто я, что продаю, кому, что болит
├── data-sources.md    ← где лежат данные бизнеса и что уже можно подключить
├── checkin.md         ← ежедневный чек-ин в 3 строки
└── decisions.md       ← журнал решений: что решили и почему
```

Эта папка потом без переделок ложится в Obsidian-волт (урок 2 потока).

## Пять скиллов

| Скилл | Что делает |
|---|---|
| `business-starter` | Точка входа. Ведёт по шагам, собирает первую систему за один проход |
| `business-context-system` | Структура папок и файлов, нейминг, генерация CLAUDE.md / AGENTS.md / about-business |
| `business-deep-research` | Исследование одного вопроса бизнеса с источниками и уровнем уверенности C1–C5 |
| `business-journal` | Ежедневный чек-ин, выбор одной привычки/рутины, разбор паттернов через 2 недели |
| `data-interpretation` | Отчёт / таблица → правильные вопросы → выводы, которые можно проверить |

Плюс два скилла безопасности (используйте до того, как что-то отдавать в облако или запускать чужое):

| Скилл | Что делает |
|---|---|
| `pii-scrub` | Обезличивает текст/таблицу до отправки в облачную модель |
| `privacy-review` | Читает чужой скилл/промт/репозиторий до запуска: куда шлёт, что читает, есть ли скрытые команды |

Каждый скилл — один файл `skills/<имя>/SKILL.md`. Можно взять один и не брать остальные.

## Три правила

1. **AI — партнёр по мышлению, не сотрудник и не юрист.** Решения принимаете вы.
2. **У каждого вывода есть уровень доверия C1–C5.** Низкий — это вопрос, а не факт.
3. **Не копируйте чужой скилл вслепую.** Прочитайте, адаптируйте под свою цель. Этот тоже.

---

## Уровни доверия C1–C5

| Уровень | Что значит |
|---|---|
| **C1** | Проверено на ваших данных, работает |
| **C2** | Подтверждено несколькими независимыми источниками |
| **C3** | Один источник или общее правило отрасли |
| **C4** | Предположение модели, логично, но не проверено |
| **C5** | Догадка. Считать вопросом |
